# Baseline Design Record

## Surface

Baseline web app, focused on the public landing page, no-login Judge Mode, analyze flow, workspace memory, and public Agreement Sheet.

## Direction

Operational SaaS for short-form video freelancers. The UI uses a restrained off-white and muted green base, charcoal text, deep green for action/healthy decisions, amber for unresolved assumptions, and muted red only for explicit rule triggers.

## Brand Assets

The app now uses a generated Baseline mark across navbar, footer, favicon, apple touch icon, Open Graph image, and manifest icons. The landing hero uses a generated workspace image that represents the actual pre-deal context instead of a decorative fake dashboard.

## Typography

Onest is the primary UI face, with JetBrains Mono for formulas and numeric traces. Letter spacing is kept at zero to avoid template-like uppercase treatment.

## Motion

Motion is limited to meaningful state changes: hero reveal, section reveal, formula drawer open/close, scope progress fill, Judge Mode step transitions, and agreement confirmation. Reduced-motion preferences remove non-essential animation timing.

## P0 Boundaries

The polished flow stays inside P0: seeded demo, live text analysis with graceful AI failure, deterministic pricing, cost profile, one-project calibration, deal options, WhatsApp copy, and public agreement. No marketplace, payment, OCR, voice, project management, subscriptions, or multi-profession template was added.

## Verification

Impeccable detector returned no findings after the font/background pass. Production frontend build, deterministic pricing tests, backend import smoke, backend E2E against local in-memory storage, and seeded API flow smoke were run.
